# Student Budgeting App (iOS)

A budgeting app built for students, focused on helping users balance spending, build healthy financial habits, and simplify money management.  

## Features

- **Modern UI**  
  Clean and intuitive interface with clear charts and dashboards for tracking spending.  

- **AI-Powered Receipt Scanning**  
  OCR (Optical Character Recognition) automatically parses receipts and updates budgets, reducing manual entry.  

- **Custom Budgeting Plans**  
  Flexible categories and personalized plans to fit individual spending habits.  

- **Secure Authentication**  
  Sign-up and login flow to protect user data and provide a safe budgeting experience.  

## Why It’s Different

Most budgeting apps are built for experienced users. This project is tailored for students who are just starting to manage their own finances. By combining automation (AI OCR) with personalization, it makes budgeting approachable and effective.  

## Tech Stack

- **iOS Development:** Swift / SwiftUI  
- **AI/ML:** OCR integration for receipt parsing  
- **Design:** Focus on simplicity, clarity, and accessibility
